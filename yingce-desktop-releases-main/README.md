# 影策个人桌面版发布

> 此目录是早期 1.3.5 发布文件的历史副本，不代表当前桌面版本。请使用 [1.3.14 完整安装版](https://github.com/yongchengjiao2-ctrl/yingce-desktop-releases/releases/tag/desktop-v1.3.14)。当前快照、提示词和发布工具位于仓库的 `desktop-release/`；不要用此目录中的旧 latest.json 进行离线安装。

Windows x64 桌面版发布仓库。程序包通过 Releases 提供，不包含个人数据或 API Key。

首次从 Releases 下载 install.ps1 和 install.cmd 到同一文件夹，双击 install.cmd。后续使用软件菜单“影策 → 安装或更新影策”。

升级保留本机接口配置、密钥、画布、素材及任务记录，不在电脑之间同步数据。

1.3.5 基于已发布 1.3.4 运行文件，增加 HTTPS 更新入口。
