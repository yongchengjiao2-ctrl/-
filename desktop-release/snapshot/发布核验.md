# 1.3.14 发布核验

基准：2026-10-27 桌面快捷方式实际启动的 `%LOCALAPPDATA%/YingceCanvas/versions/1.3.13`。不是旧安装包，也不是未安装的源码候选。

- 原桌面运行文件共 32,220 个，约 2.15 GB。相对上次公开 1.3.13 安装包有 326 个前端文件新增或变更，均纳入本次发布。
- 分镜入口、单次调用锁、非流式请求策略、最终结果等待、输出整理以及各模块内系统提示词均逐字节保留。37 个有本地独立源码的模块也与实装哈希一致。
- 9 项数据库后台提示词在一致性只读事务中导出，逐字对比通过。新数据库迁移后，真实打包后端启动及建立桌面会话后，9 项启用模板仍与桌面原文一致。
- 73 项内置技能的名称、说明、指令、版本和内容哈希在后端启动后与快照一致。新桌面账号会恢复原桌面已添加的技能；旧桌面账号按 active 状态迁移。
- 协议注册共 14 项；有独立包的协议均核对原包 SHA256。专用 JSON 协议随包导入，不含原电脑 API Key。
- 13 项单次调用与非流式回归通过，包括真实已安装章节入口委托、重复提交拦截、失败不自动二次请求、等待不订阅文本流和取消。
- 新数据库导入、旧数据库备份、模板逐字核对、配置保留、重复启动幂等与显式重新应用测试通过。备份内容与迁移前数据一致。
- 完整 ZIP 共 32,314 项，每项解压内容 SHA256、路径、大小均对清单通过；迁移脚本与提示词 JSON 对源码通过。兼容旧安装器路径白名单，安装器保留 Windows PowerShell 5.1 所需 UTF-8 BOM。
- Electron 启动入口仅增加一次状态迁移与版本标识，ASAR 结构和入口语法验证通过；该差异在 manifest.json 的 packagingAdapter 单独列出。其余原软件运行文件与桌面实装一致。
- 只排除非运行功能的本机审计输入 extraction-live-test-input.json。个人数据库、项目、小说正文、浏览器配置、密钥与机器账号不发布。公共文本快照扫描未发现真实凭证模式，插件文档中的重复字符示例已单独核对。
